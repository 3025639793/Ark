# Ark · 本地相册

一款离线使用的 Windows 图片相册，用来收藏、分类和浏览喜欢的图片。图片与分类保存在本机，无需账号或服务器。

## 下载

**[下载 Windows 版](https://github.com/3025639793/Ark/releases/latest)**

适用于 Windows 10 / 11（x64）。在发布页的 Assets 中选择 `Ark-Setup-…-x64.exe` 安装；已有安装版可在「设置 → 软件更新」升级。也提供免安装 ZIP，免安装版需手动更新。

## 功能

- 导入图片或多层文件夹，预览目录并选择角色分类，自动跳过重复图片。
- 按角色、作品、文件夹和标签整理，支持搜索、收藏、随机排序、批量修改与删除。
- 使用统一密码加密图片，锁定时仅在加密库显示，临时解锁后回到原分类。
- 查看原图、缩放浏览，支持随机展示和自动播放。

## 使用说明

导入会创建副本，批量删除仅影响 Ark 内的图片，原始文件夹不受影响。

加密密码无法找回。加密库中的模糊封面仍会显示大致颜色和轮廓。

备份前退出软件，复制设置中「打开本地数据目录」里的完整数据文件夹。

更多操作见 [使用说明](WINDOWS-开始使用.txt)。
