# Ark · 本地相册

离线使用的 Windows 图片相册：导入喜欢的图片，按角色、作品与标签整理，创建真正加密的收藏库，随机看看自己的收藏。无需账号、云服务器或订阅。

## Windows 使用

**[下载 Windows 安装版](https://github.com/3025639793/Ark/releases/latest)**

打开发布页面，在 **Assets** 中下载 `Ark-Setup-0.8.1-x64.exe`，双击安装。安装完成后可从桌面或开始菜单启动 Ark。无需安装 Node.js。

已有 v0.2 / v0.3 免安装版：先退出旧版，再运行这个安装程序。安装版沿用 `%APPDATA%\Ark\album-data`，旧图片、分类和加密库会继续保留。旧版没有更新功能，首次升级到安装版须手动进行。

同时提供 `Ark-0.8.1-windows-x64.zip` 免安装包：完整解压后运行 `Ark.exe`。免安装版不提供软件内更新；`Source code` 是源码，不是安装包。

这个版本支持 Windows 10 / 11 的 x64 电脑。它是未签名的自制应用；Windows 可能显示发布者未验证的提示。

1. 在左侧选择图片库，点击「导入图片」，或把图片拖进窗口。支持 JPG / PNG / GIF / WebP，单张最多 25 MB。
2. 点击图片填写角色、作品、标签、画师和来源。也可以选择「批量整理」。
3. 点击「新建库」，可创建普通库，或使用统一密码隐藏整个库的图片与分类。
4. 点击「随机展示」换一张图片，或按 5 / 10 / 30 秒自动切换。
5. 在「设置」中指定哪些库参与随机展示，以及是否允许展示加密库。

## 查看原图

打开图片详情后，点击「查看原图」或直接点击图片，即可在软件内查看完整分辨率的原文件。默认适应窗口，可切换到「100% 原始尺寸」、放大缩小，拖动或滚动查看细节；Ctrl + 滚轮缩放。按 Esc 或「返回详情」关闭原图，仍停留在图片详情。

左右切图按钮位于图片两侧的独立空间，保持在图片上层。加密图片的原图查看沿用当前解锁权限，不会额外导出明文文件；关闭单图详情、锁定或解锁到期后，原图界面也会关闭并清除显示。

## 角色收藏墙与返回

点击左侧「角色」标题打开收藏墙，再点击角色卡片查看该角色的图片；下方角色列表是同一套角色页面的快捷入口。角色页顶部有「返回角色收藏墙」，收藏墙可再返回全部图片，宽窗口也可点击面包屑导航。切换页面会清除搜索与分类筛选，避免残留条件使图片看起来消失。角色页的图片数量和大小按当前筛选结果统计。

## 美露莘主题

界面采用海沫绿、淡紫与暖白配色，使用选定的美露莘头像作为 Logo、窗口图标和 Windows 应用图标。软件内仅在侧栏保留一处小尺寸 Logo；首页、空白状态和访客证不再重复展示 Logo。访客证与来信等彩蛋继续保留。

在「设置 → 美露莘收藏室 → 选择主题图片」中，可以从你的本地图片文件夹中选择喜欢的美露莘图片作为首页装饰。它会复制到本地数据目录并持久保存，不上传到云端；装饰图会在加密库锁定时仍显示。支持 JPG / PNG / GIF / WebP，最多 10 MB。

点击首页来信文字可查看原创小纸条；点击 Logo 三次可以发现海沫村访客证。在设置中关闭「显示小彩蛋与海沫村来信」即可关闭这些互动。减少动态效果的系统偏好也会被遵守。

v0.8.0 增加统一密码和独立「加密库」汇总入口，保留 v0.7.0 的目录树预览、父级角色继承及可选的重复图片分类更正。v0.6.2 的角色导航和布局修复继续保留。v0.6.1 更新 Logo 并减少重复展示；v0.6.0 的图片级加密、限时解锁、文件夹角色分类、内容去重和导入保护继续保留。

## 软件内更新（Windows 安装版）

安装版启动后联网检查 GitHub Releases。发现较新稳定版本时显示提示，在「设置 → 软件更新」中也可以手动检查。

1. 点击「下载更新」，下载完成前可以继续浏览。
2. 下载完成后点击「重启并安装」，确认后关闭相册并运行新版安装程序。
3. 安装完成后重新启动，原有数据继续使用，加密库保持锁定。

不会自行下载，也不会在普通退出时偷偷安装。导入或批量删除期间，下载和安装按钮暂时禁用。网络不可用不影响本地相册，稍后可重新检查。

后续版本必须继续发布安装 EXE、对应 `.blockmap` 和 `latest.yml`，才能被软件发现。每次发布流程会核对安装包的 SHA-512 与更新元数据。当前应用未签名，没有证书签名验证；更新使用 HTTPS 获取这个仓库的发布文件并验证文件散列。

## 文件夹导入与批量删除

点击「导入文件夹」选择你的本地图片目录，先预览支持图片的完整目录树；此时尚未写入图片库，取消即可退出。

1. 勾选作为角色分类的文件夹，可修改其角色名称。该文件夹及所有子目录的图片都沿用这个角色。
2. 更深层也勾选了角色时，使用距离图片最近的已勾选文件夹。例如勾选「作品/角色甲」，其下「壁纸/横屏」里的图片仍归角色甲，不会创建“壁纸”或“横屏”角色。
3. 「快捷勾选」可选某一层，再逐项调整；所选根目录为第 1 层。没有分配角色的图片仍保留完整目录分类。
4. 核对图片数、角色数和分类示例后点击开始导入。勾选只决定角色归属，所有支持图片都会导入，不是只导入勾选的目录。
5. 如需修正旧版按最内层文件夹分错的角色，勾选「同时更正重复图片的角色分类」后重新导入。只更新预览中已分配角色的重复图片，保留其他信息及加密状态；没有分配角色的重复图片保持原样。该选项默认关闭。

软件读取目录及子目录中支持的图片，跳过其他文件，并显示成功、重复、分类更正和失败数量。导入是复制操作，不修改原目录。

目录分类保留所选目录名称和相对层级。例如 `图片\原神\芙宁娜\a.png` 会记录为 `图片/原神/芙宁娜`。在「所有文件夹分类」下拉框选择这个路径即可筛选；选择父级 `图片/原神` 时会包含下级文件夹。也可以搜索路径，或在图片详情中修改文件夹分类。角色由导入预览中的选择决定，默认不自动把最内层目录当成角色。它沿用文件夹命名，不识别画面中的角色。相同图片按内容 SHA-256 去重，改名也会跳过；去重范围为同一图片库。旧记录会在导入时补充指纹。

点击「批量整理」，勾选图片或「全选当前结果」，然后点击「删除所选」。确认后删除 Ark 内的副本及分类，**不删除原始目录中的文件**。筛选后的全选仅选择当前筛选结果，其他图片不受影响。每批最多 500 张，大量选择会分批删除；遇到错误会保留尚未删除的选择。删除无法撤销。

旧版升级：先退出 Ark，将新版完整解压到新文件夹，运行新的 `Ark.exe`。数据仍使用原来的本地数据目录，旧分类和加密库无需迁移。不要让两个版本同时操作相同目录。

## 统一密码与加密库

每份本地相册数据只设置一个统一密码。首次点击「加密图片」或左侧「加密库 → 设置统一密码」时，输入并确认至少 8 个字符的密码；之后新加密的图片和新建整库加密都使用它，不再为每张图片设置不同密码。密码区分大小写，空格原样保留，可勾选「显示密码」核对。本次运行中已验证统一密码后，加密其他图片可直接确认；退出或「锁定全部」会清除这个缓存。

左侧「加密库」是跨图片库的汇总视图，不搬动图片、不复制图片，原来的库、角色和文件夹分类保持不变。点击其中一张锁定图片可临时单独查看，关闭详情就重新锁定；「解锁全部」可选择 5 / 15 / 30 / 60 分钟或本次软件运行期间查看，时间到后自动隐藏。「锁定全部」立即清除查看权限和缓存密钥。查看解锁与永久解除加密是两个操作，后者在详情中明确确认。

单独加密隐藏图片及详细信息，角色、作品、相对目录、大小、导入日期和去重指纹仍可见；若需要连分类也隐藏，可以新建整库加密。旧式整库加密在未解锁时只显示一个锁定库入口，隐藏库内图片和分类，解锁后才展开其中图片；其查看权限以整个库为单位。

### 旧密码兼容

尚未设置统一密码时，第一次成功输入旧图片或旧库的原密码，会把它作为统一密码并接入该内容。已经设置统一密码，而旧内容使用其他密码时，在解锁窗口输入统一密码，并在「旧图片或旧库原密码」中填写原密码。验证成功后接入统一密码，以后只需统一密码。旧文件的原密码无法被跳过，损坏或丢失的加密数据也无法通过新设密码恢复。

接入统一密码只更新密钥封装，不重写图片文件。已经接入以及新加密的内容需要 v0.8.0 或更新版本打开。升级前后均可退出软件并完整复制数据目录备份。

读取失败、目录解析损坏和密码验证失败分别提示。旧格式没有独立校验信息时，错误密码和加密数据损坏无法完全区分，软件会如实提示两种可能。

删除角色分类：进入一个角色，在顶部点击「删除当前角色分类」，确认后只清除角色归属，保留图片、文件夹分类及加密状态。

导入中阻止普通关闭、锁定和更新安装；Windows 锁屏的锁定会延后到导入完成。强制结束进程或断电后，重新选择相同文件夹，已完成的图片自动跳过。导入每张图片独立保存，不能保证强制终止时正在写入的那一张完成。

## 加密存储如何工作

- 原图与分类信息使用 AES-256-GCM 加密。文件名、图片名称、角色、标签等保存在加密目录清单中，不以明文写入加密库目录。
- 统一密码使用独立随机盐，通过 scrypt（N=32768、r=8、p=1）派生主密钥；各图片或图片库的数据密钥使用 AES-256-GCM 封装。每次加密使用新随机 IV，兼容验证旧格式的独立密码。
- 密钥仅保留于进程内存；单张或限时查看授权到期后清零相应数据密钥。统一密码的加密操作缓存持续到退出或锁定全部，它不会自动授予其他图片查看权限。锁定全部会清零所有缓存密钥并关闭图片展示。
- 桌面浏览会话使用内存分区，图片响应禁止缓存；不会为加密图片生成明文缩略图文件。
- 默认闲置 5 分钟自动锁定，可改为 1 / 15 分钟或关闭。随机自动播放不会延长解锁时间。Windows 锁屏也会锁定加密库。
- **密码无法找回。请记住密码，并备份数据。**
- 导入是复制操作：加密库保存加密副本，你原来文件夹中的图片不会被删除或加密。
- 图片库名称、是否加密、随机展示设置和库的存在是明文信息。软件不承诺隐藏这些信息。
- 显式下载加密库原图或导出分类会产生明文文件；分类导出前会提示确认。

## 随机展示规则

普通库：只需开启该库「参与随机展示」。

加密库：必须同时满足 **当前已解锁 + 全局允许展示加密库 + 该库参与随机展示**。

单独加密的图片需要全局允许、所在库允许，并处于限时或本次运行解锁状态；仅查看单图不会进入随机展示。

加密库默认不参与；全局允许开关每次启动默认关闭。锁定库不能通过随机接口或图片地址绕过保护。随机选择会在存在多张候选图片时避免连续出现同一张。

## 本地数据与备份

Windows 数据默认位于 `%APPDATA%\Ark\album-data`，也可在设置中点击「打开本地数据目录」。图片和分类均保存在本机，不上传到 GitHub或云端。

完整备份：退出 Ark，复制整个 `album-data` 文件夹。恢复：退出软件，将备份完整放回原位置后再启动。加密库备份仍然需要原密码。

「导出当前库分类」只导出当前解锁库的 JSON 分类记录，不包含原图，不能替代完整备份。目前不提供分类 JSON 导入。

## 开发与打包

需要 Node.js 24。

```sh
npm ci
npm start
```

不安装桌面依赖也可使用本地浏览器模式：

```sh
node server.mjs
```

打开终端输出的本地地址即可。服务只监听 `127.0.0.1`，不提供局域网或外网访问。浏览器模式数据位于项目 `data/`，与桌面版本的数据目录不同；可通过 `ARK_DATA_DIR` 指定目录。不要同时运行两个进程操作同一个数据目录。

Windows 打包（生成安装 EXE、免安装 ZIP 和更新元数据）：

```sh
npm run build:win
```

产物位于 `release/`。应用依赖已打包，使用者无需安装 Node.js。

## 验证

```sh
npm run check
npm test
```

测试覆盖本地 API 保护、加密文件与元数据不落明文、错误密码、篡改检测、闲置锁定、重启后保护、随机展示权限组合、并发导入、目录分类持久化、按库批量删除，以及 DOM 交互中的导入、分类、建库、随机展示与锁定清屏。

自动界面测试使用 jsdom，不替代 Windows 实机启动与视觉检查。安装包在 GitHub Actions 的 Windows 环境中构建并验证更新元数据；首次安装与实际跨版本更新尚待 Windows 实机确认。

## 发布版本

推送与 `package.json` 版本一致的 `v*` 标签，会触发 `.github/workflows/release-windows.yml`。GitHub Actions 在 Windows 上检查、测试、打包并验证更新元数据，将安装 EXE、ZIP、blockmap、latest.yml 和 SHA-256 校验文件发布到 Releases。
